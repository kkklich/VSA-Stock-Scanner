# StockPilot — VSA Stock Scanner (GPW)

VSA (Volume Spread Analysis) scanner for the Warsaw Stock Exchange.

## Layout
- `frontend/` — React + TypeScript + Vite app (ranking table, TradingView charts, VSA overlays)
- `backend/`  — ASP.NET Core .NET 8 Web API (scanner feed, signals feed)
- `.github/workflows/` — CI/CD (GitHub Actions)
- `agent/` — project blueprint & reference material (gitignored)
